# tz_pg

TrustZone-enabled firmware project built and discussed in [TrustZone Demystified: Part 1](https://evanstoddard.com/posts/trustzone-demystified_part_1/).  The project consists of a Secure image and a NonSecure image that communicate via Non-Secure Callable (NSC) functions.

## Hardware

- **Board:** NUCLEO-H563ZI
- **MCU:** STM32H563 (Cortex-M33)
- UART output is on USART3, configured as a Secure peripheral

## Project Structure

```
Secure/           Secure firmware image
NonSecure/        NonSecure firmware image
Secure_nsclib/    NSC library generated by the Secure build and linked into NonSecure
scripts/
  build.sh        Builds both images in the correct order
  flash.sh        Flashes both images to the target
```

The Secure image is built first.  As part of that build, the toolchain generates `Secure_nsclib/secure_nsclib.o`, which contains the NS-side import stubs for all `CMSE_NS_ENTRY` functions.  The NonSecure image is then built and links against that library.

## Prerequisites

### ST's Fork of OpenOCD

Flashing requires **ST's fork of OpenOCD**, which ships with STM32CubeIDE and is also available from ST's GitHub.  The standard upstream OpenOCD release does not include support for STM32H5 targets.  Make sure ST's OpenOCD is on your `PATH` before running `flash.sh`.

### Option Bytes

TrustZone must be enabled on the target via option bytes before this firmware will run correctly.  This is a one-time step done through **STM32CubeProgrammer**:

1. Connect the board and open STM32CubeProgrammer.
2. Under **OB (Option Bytes)**, enable the TrustZone option byte (`TZEN`).
3. Set the Secure Watermark for flash bank 2 to mark it as NonSecure (start sector `0x1`, end sector `0x0`).
4. Apply and disconnect.

The `flash.sh` script does not handle option bytes, so this must be done before flashing for the first time or after switching from a non-TrustZone image.

## Building

```bash
./scripts/build.sh
```

Configures and builds both the Secure and NonSecure images using the CMake Debug preset.

## Flashing

```bash
./scripts/flash.sh
```

Flashes both ELF images to the board and resets it.  Both images must be built before running this script.
